**Goal:** find out whether a cross-encoder reranker over the fused top N separates the near-twin
recipes that M3's retrieval confuses, and keep the better of two models.

**Architecture:** a gate first (recall at the candidate depth, CPU only), then an in-process
`Reranker` (`src/recall/rerank.py`, transformers, GPU only, weights pinned and offline) that
`retrieve.search` applies to the fused top N, a reranked matrix in `recall.eval`, one GPU run in a
CUDA container on the shared box, and the decision rules fixed in the spec.
Spec: `docs/superpowers/specs/2026-11-13-m4-reranker-design.md`.

**Tech Stack:** Python 3.12, psycopg 3, pgvector, transformers + torch (cu126, from `uv.lock`),
`BAAI/bge-reranker-v2-m3`, `Qwen/Qwen3-Reranker-4B`, podman, pytest, ruff (line length 100).

## Amendments to the spec

1. **Box checks are a smoke command, not marked tests.** `tests/unit` and `tests/integration` are
   not on the publish allowlist, so the box cannot run `needs_gpu` tests from its snapshot. The
   GPU checks the spec lists under "Box only" are `python -m recall.rerank smoke --model <name>`
   (Task 7), run inside the eval image (Task 11). Unit tests cover everything that needs no
   weights.
2. **The 512 budget counts content tokens.** Query plus candidate get 512 tokens, the same for
   both models; each model's own special tokens and prompt template (Qwen's instruction and chat
   frame) come on top. Otherwise the 4B would see less ticket text than bge, and the comparison
   would not be fair.
3. **The protocol takes candidates as (problem, solution) pairs**, not joined strings:
   `score(query: str, candidates: list[tuple[str, str | None]]) -> list[float]`. The budget split
   between problem and solution has to happen at token level, inside the adapter.
4. **`all` is depth 200** (`ALL_DEPTH = 2 * retrieve.POOL`): two arms of 100 cannot fuse into more,
   so recall at 200 is recall over the union, and it divides by `|relevant|` for every group here.
5. **Task 7 deviates from the code listed there (2026-11-13).** The lock pins transformers 5.16.1,
   which has no `tokenizer.prepare_for_model`, so `BgeReranker` builds its pair by hand
   (`bge_input_ids`: `<s> query </s></s> document </s>`, from the tokenizer's cls and sep ids; the
   512 budget still counts content tokens only, so a pair is 516 ids). Both adapters pass `dtype=`
   (the documented name in 5.16.1) instead of `torch_dtype=`. Two tests cover the pair layout and
   its budget, and one pins both revisions. The commits are `10218a0` and `730f181`; the code in
   the repo is the reference, not the Task 7 listing below.
6. **Tasks 8 and 10 deviate slightly (2026-11-13).** `recall.eval.main` builds the rerankers right
   after validating its arguments and before the embedder and the index (fix `b995cfd`), so a
   missing GPU or weights fails in seconds and not after the CPU index build; an unknown reranker
   name or `--rerankers` without `--depth` is an argparse error, pinned by `tests/unit/test_eval_cli.py`.
   `infra/eval/Dockerfile` copies only `src`, `profiler` and `insight` (the eval imports nothing
   else; `fixtures` is not needed) and its build-time check also asserts that torch is the CUDA
   build.

```python
# The deepest list there is: two arms of POOL fuse into at most 2 * POOL ids, so recall at this
# depth is recall over the union of both pools, the ceiling of any rerank over them.
ALL_DEPTH = 2 * retrieve.POOL


def parse_depths(text: str) -> tuple[int | str, ...]:
    """`10,50,all` as (10, 50, "all"); a depth is a positive integer or `all`."""
    depths: list[int | str] = []
    for part in text.split(","):
        if part == "all":
            depths.append("all")
        elif part.isdigit() and int(part) > 0:
            depths.append(int(part))
        else:
            raise ValueError(f"not a depth: {part!r}")
    return tuple(depths)


def _depth(depth: int | str) -> int:
    return ALL_DEPTH if depth == "all" else int(depth)


def add_depths(
    entry: dict,
    rankings: dict[str, list[str]],
    relevant: dict[str, set[str]],
    group: dict[str, str],
    depths: tuple[int | str, ...],
    per_group: bool = False,
) -> dict:
    """Add macro recall at each depth to a `score` entry (and to its groups when per_group), keyed
    by the depth as written. MRR and nDCG stay at the entry's own k."""
    for depth in depths:
        n = _depth(depth)
        scored = score(rankings, relevant, group, n, per_group)
        entry.setdefault("recall_at_depth", {})[str(depth)] = scored[f"recall_at_{n}"]
        if per_group:
            for name, metrics in scored["groups"].items():
                at = entry["groups"][name].setdefault("recall_at_depth", {})
                at[str(depth)] = metrics[f"recall_at_{n}"]
    return entry
```

```python
"""Rerankers: score each fused candidate against the query, precision where fusion gave recall.

A reranker reads one query and the candidates' texts and returns one score per candidate, higher
is more relevant. The real adapters are GPU only (operator, 2026-11-13) and load pinned weights
offline, like E5Embedder. OverlapReranker is a deterministic stand-in, so retrieval and the eval
are testable with no torch, no GPU and no download.
"""

from __future__ import annotations

import re
from collections.abc import Sequence
from typing import Protocol

QUERY_CAP = 128  # query tokens a pair keeps; a title or head query never reaches it
PAIR_BUDGET = 512  # content tokens per pair, the same for every model (plan amendment 2)
_WORD = re.compile(r"[a-z0-9äöüß_]+")

Candidate = tuple[str, str | None]  # problem text, solution text or None


class Reranker(Protocol):
    identity: str
    device: str

    def score(self, query: str, candidates: list[Candidate]) -> list[float]: ...


class OverlapReranker:
    """The share of the query's distinct words that occur in the candidate.

    Not a model and not pretending to be one: enough to give the rerank path a real ordering in
    tests. Its identity begins with `overlap:` so a report made with it cannot pass for a model's.
    """

    identity = "overlap:words"
    device = "cpu"

    def score(self, query: str, candidates: list[Candidate]) -> list[float]:
        words = set(_WORD.findall(query.casefold()))
        scores = []
        for problem, solution in candidates:
            found = set(_WORD.findall(f"{problem} {solution or ''}".casefold()))
            scores.append(len(words & found) / len(words) if words else 0.0)
        return scores


def fit(
    query: Sequence[int],
    problem: Sequence[int],
    solution: Sequence[int] | None = None,
    *,
    sep: Sequence[int] = (),
    total: int = PAIR_BUDGET,
    query_cap: int = QUERY_CAP,
) -> tuple[list[int], list[int]]:
    """Cut token ids to one pair's budget: the query to query_cap, the candidate to the rest.

    With a solution, problem and solution get half of the candidate's share each (the separator
    counts against it) and a side that needs less leaves the rest to the other, so a long
    description cannot push the fix out of the window. Returns (query ids, candidate ids)."""
    q = list(query[:query_cap])
    room = total - len(q)
    if solution is None:
        return q, list(problem[:room])
    room -= len(sep)
    take_problem = min(len(problem), max(room // 2, room - len(solution)))
    take_solution = min(len(solution), room - take_problem)
    return q, list(problem[:take_problem]) + list(sep) + list(solution[:take_solution])
```

```python
        )
        for h in hits
    ]

    order = sorted(range(len(hits)), key=lambda i: (-scores[i], i))
    return [replace(hits[i], rerank=float(scores[i])) for i in order]
```

```python
    if not torch.cuda.is_available():
        raise RuntimeError("the reranker is GPU only: no CUDA device is visible")
    return "cuda"


def _ids(tokenizer, text: str) -> list[int]:
    return tokenizer.encode(text, add_special_tokens=False)


def fitted(tokenizer, query: str, candidate: Candidate) -> tuple[list[int], list[int]]:
    """Query and candidate as token ids within the pair budget (see fit)."""
    problem, solution = candidate
    return fit(
        _ids(tokenizer, query),
        _ids(tokenizer, problem),
        None if solution is None else _ids(tokenizer, solution),
        sep=_ids(tokenizer, SOLUTION_SEP),
    )

    """One Qwen3-Reranker input: the card's frame around instruction, query and document."""
    q, doc = fitted(tokenizer, query, candidate)
    head = _ids(tokenizer, f"{QWEN_PREFIX}<Instruct>: {INSTRUCTION}\n<Query>: ")
    return head + q + _ids(tokenizer, "\n<Document>: ") + doc + _ids(tokenizer, QWEN_SUFFIX)

    """`BAAI/bge-reranker-v2-m3`, a cross-encoder: the raw relevance logit is the score."""

    def __init__(self, model: str = BGE_MODEL, revision: str = BGE_REVISION) -> None:
        import torch
        from transformers import AutoModelForSequenceClassification, AutoTokenizer

        self._torch = torch
        self.device = _gpu(torch)
        self._tokenizer = AutoTokenizer.from_pretrained(
            model, revision=revision, local_files_only=True
        )
        self._model = (
            AutoModelForSequenceClassification.from_pretrained(
                model, revision=revision, local_files_only=True, torch_dtype=torch.float16
            )
            .eval()
            .to(self.device)
        )
        self.identity = f"bge:{model}@{revision}"

    def score(self, query: str, candidates: list[Candidate]) -> list[float]:
        torch = self._torch
        scores: list[float] = []
        for start in range(0, len(candidates), BATCH):
            pairs = [
                self._tokenizer.prepare_for_model(*fitted(self._tokenizer, query, c))
                for c in candidates[start : start + BATCH]
            ]
            batch = self._tokenizer.pad(pairs, return_tensors="pt")
            batch = {name: tensor.to(self.device) for name, tensor in batch.items()}
            with torch.no_grad():
                logits = self._model(**batch).logits.view(-1).float()
            scores.extend(logits.cpu().tolist())
        return scores

            .to(self.device)
```
